# English Card Game

A full-stack English vocabulary learning platform built with Next.js 16, TypeScript, PostgreSQL, and a responsive Thai-first learning UI.

The app turns vocabulary practice into card-based quiz sessions with learning styles, story cards, progress tracking, admin tools, and Docker-ready deployment.

## Highlights

- Multiple quiz modes: multiple choice, typing, inverted typing, timed quiz, think-and-reveal, and timed reveal.
- Study cards for different learning styles, including fast review, wide vocabulary pools, custom decks, and story-based cards.
- Progress tracking with XP, streaks, mastery state, answer accuracy, session history, and dashboard statistics.
- PostgreSQL-backed API routes for users, vocabulary, study cards, game sessions, achievements, settings, and leaderboard data.
- Admin pages for user management, vocabulary management, story cards, seed vocabulary, and CSV imports with progress streaming.
- JWT/PIN authentication with admin-only route protection.
- Theme system powered by CSS variables, Tailwind CSS, and a theme editor.
- Production Docker image using Next.js standalone output.

## Quick Start

```bash
npm install
cp docker.env.example .env
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The local app needs a PostgreSQL database for authenticated and persisted features. Some game data can still load from seed vocabulary while developing the UI.

## Environment Variables

Create `.env` in the project root. Next.js loads `.env*` files from the root folder, not from `src/`.

```bash
DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/english_card_game
DATABASE_SSL=false
DATABASE_SSL_REJECT_UNAUTHORIZED=false
DATABASE_POOL_MAX=5
DATABASE_CONNECTION_TIMEOUT_MS=20000
JWT_SECRET=change-this-long-random-secret
NEXT_PUBLIC_API_URL=http://localhost:3000
```

For Docker Compose, use `docker.env.example` as the starting point.

## Database Setup

The project expects PostgreSQL tables for users, vocabulary, sessions, study state, and settings. The schema is maintained partly through app-side schema helpers and SQL migration files.

Useful SQL files:

- `database.study.sql` adds study cards, card words, exam-ready words, user game settings, vocabulary categories, and indexes.
- `database.unify-vocabulary.sql` migrates custom vocabulary into the main `vocabulary` table and updates related references.

Typical setup flow:

```bash
psql "$DATABASE_URL" -f database.study.sql
psql "$DATABASE_URL" -f database.unify-vocabulary.sql
```

Only run migration files that match the current state of your database.

## Docker

Build and run the production container:

```bash
docker compose --env-file .env up -d --build
```

The compose file expects an external PostgreSQL Docker network. Configure it with:

```bash
POSTGRES_DOCKER_NETWORK=postgresql-server_default
```

The Dockerfile uses `output: "standalone"` from `next.config.ts`, so the final image contains the minimal runtime files generated by Next.js.

## API Areas

The backend uses Next.js App Router route handlers under `src/app/api`.

- `auth`: PIN login and token verification.
- `game`: vocabulary selection, study-state sync, answer submission, and session lifecycle.
- `user`: dashboard, progress, mastered words, and settings.
- `admin`: users, stats, app settings, vocabulary, CSV import, and story cards.
- `vocabulary`: public/user vocabulary CRUD and batch operations.
- `leaderboard`, `achievements`, `health`: supporting app endpoints.

## Game Modes

| Mode | Description |
| --- | --- |
| `multiple-choice` | Pick the correct Thai translation from answer choices |
| `typing` | Type the answer instead of choosing an option |
| `invert` | Reverse-direction typing practice |
| `think-reveal` | Think first, reveal the answer, then self-assess |
| `timed` | Answer within the timer |
| `timed-reveal` | Timed self-assessment reveal mode |

## Learning System

- Mark levels control how often a word appears again: normal review, remembered, deeply remembered, or skipped.
- Study cards can lock small focused sets or wider word pools depending on learning style.
- Story cards combine English passages, Thai translations, glossary items, idioms, and quiz decks.
- Exam-ready words unlock once enough mastered words are available.
- Spaced repetition helpers use an SM-2-style interval update for review scheduling.

## Theme System

Themes are defined in:

```text
src/themes/themes.ts
```

The app injects theme values through CSS custom properties, so components can use stable semantic tokens like `--bg-base`, `--text-primary`, and `--accent-primary`.

Built-in themes include Midnight Ink, Paper Light, Neon Dojo, Sakura, and Ocean Deep.
